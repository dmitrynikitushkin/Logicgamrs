# Думалки

Логические игры для детей от 4 лет. Работают без интернета, задания читаются вслух.
Есть Android-приложение (APK), а ту же страницу можно открыть в любом браузере.

## Игры

| Игра | Что делает ребёнок |
|---|---|
| Что лишнее? | Находит картинку, которая не подходит к остальным (фрукты, животные, транспорт…) |
| Продолжи ряд | Угадывает следующую бусину: АБАБ → ААБ → АБВ |
| Найди тень | Подбирает к картинке её силуэт |
| Посчитай | Считает предметы (нажатие на каждый проговаривает номер) и выбирает цифру |
| Где больше? | Сравнивает две тарелки: где больше, где меньше |
| Найди пару | Игра на память: 3 → 4 → 6 пар карточек |

После каждой игры сразу предлагаются две другие игры, а на главном экране есть кнопка «Случайная игра».
Сложность растёт от раунда к раунду, ошибки не наказываются.

## Установить на телефон

1. Скачайте `dist/dumalki.apk` на телефон (или возьмите свежую сборку в GitHub → Actions → Build APK → Artifacts).
2. Откройте файл и разрешите установку из этого источника.
3. Для озвучки нужен русский голос: Настройки → Синтез речи (обычно «Google Синтез речи» уже есть).

Кнопка «Назад» в игре возвращает к списку игр, а со списка закрывает приложение.

## Структура

```
app/assets/index.html     все игры (HTML + CSS + JS, один файл)
app/assets/fonts/         шрифты Comfortaa и Rubik (для работы без интернета)
app/src/…/MainActivity.java  WebView + голос Android (TextToSpeech)
app/AndroidManifest.xml
app/res/                  иконка и название
build.sh                  сборка APK без Android Studio и Gradle
```

## Сборка

На Ubuntu/Debian:

```bash
sudo apt-get install -y android-sdk-platform-23 aapt dalvik-exchange zipalign apksigner default-jdk
./build.sh            # → dist/dumalki.apk
```

При первой сборке создаётся ключ подписи `keystore/dumalki.jks` (в git не попадает).
Обновление ставится поверх старой версии только если APK подписан тем же ключом.
Чтобы сборки в GitHub Actions подписывались постоянным ключом, добавьте в Settings → Secrets
`KEYSTORE_B64` (вывод `base64 -w0 keystore/dumalki.jks`) и `KS_PASS`.

Новую версию отмечайте в `app/AndroidManifest.xml`: увеличьте `versionCode` и `versionName`.
