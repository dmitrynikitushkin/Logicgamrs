# Думалки

Логические игры для детей от 4 лет. Работают без интернета, задания читаются вслух.
Есть Android-приложение (APK), а ту же страницу можно открыть в любом браузере.

## Игры

| Игра | Что делает ребёнок |
|---|---|
| Что лишнее? | Находит картинку, которая не подходит к остальным (фрукты, животные, транспорт…) |
| Продолжи ряд | Угадывает следующую бусину: АБАБ → ААБ → АБВ |
| Найди тень | Подбирает к картинке её силуэт |
| Посчитай | Считает предметы (нажатие на каждый проговаривает номер) и выбирает цифру |
| Где больше? | Сравнивает две тарелки: где больше, где меньше |
| Найди пару | Игра на память: 3 → 4 → 6 пар карточек |

### Цифры от 0 до 10

| Игра | Что делает ребёнок |
|---|---|
| Цифры | Нажимает цифру и видит столько же картинок (рядами по 5), слышит название. Кнопка «Считаем до 10» считает вслух вместе с ребёнком |
| Найди цифру | Находит цифру, которую назвал голос |
| Сколько это? | Подбирает к цифре тарелку с нужным количеством (с 4-го раунда бывает и пустая, ноль) |
| Какое пропало? | Находит пропущенное число в ряду; в последних раундах счёт назад |
| Сложение | Складывает по картинкам: до 5, потом до 7, потом до 10 |
| Вычитание | «Было пять, два убрали»: убранные картинки зачёркнуты; в конце бывает ответ 0 |

### Буквы: русский и нидерландский алфавит

Для каждого алфавита по три режима:

| Режим | Русский | Nederlands |
|---|---|---|
| Азбука: нажми букву, увидишь картинку и услышишь название | Азбука | Alfabet |
| Найди букву по звуку (с 4-го раунда маленькие буквы) | Найди букву | Zoek de letter |
| С какой буквы начинается слово | Первая буква | Eerste letter |

Нидерландские задания звучат на нидерландском. Для озвучки на телефоне должен быть скачан голос
Nederlands (Настройки → Синтез речи → Google → Установить голосовые данные). Если его нет,
приложение молчит и показывает подсказку, а не читает нидерландский русским голосом.

### Ловкость (аркады, как на старой приставке)

Собственные игры в жанрах классических аркад, медленные и прощающие ошибки:

| Игра | Жанр | Управление |
|---|---|---|
| Ловим фрукты | ловилка | водить пальцем или ◀ ▶ |
| Зайка-прыгун | бегалка с прыжками (можно двойной прыжок) | нажать на экран или ПРЫГ |
| Гусеница | «змейка»: проходит сквозь стены, при укусе хвостика только теряет сердечко | свайп, нажатие или крестовина |
| Кубики | падающие блоки, сначала маленькие фигуры | ◀ ⟳ ⤓ ▶ или нажатие по краям/центру поля |
| Кирпичики | разбей стенку мячиком | водить пальцем, ПУСК |
| Звёздный патруль | космическая стрелялка, корабль стреляет сам | водить пальцем или ◀ ▶ |

В каждой аркаде 3 сердечка (в «Ловим фрукты» 5), есть рекорд и автопауза при сворачивании.
Работает и клавиатура: стрелки, пробел, P или Esc для паузы.

После каждой игры сразу предлагаются две другие игры (одна «думалка» и одна аркада), а на главном экране есть кнопка «Случайная игра».
Сложность растёт от раунда к раунду, ошибки не наказываются.

## Установить на телефон

1. Скачайте `dist/dumalki.apk` на телефон (или возьмите свежую сборку в GitHub → Actions → Build APK → Artifacts).
2. Откройте файл и разрешите установку из этого источника.
3. Для озвучки нужен русский голос: Настройки → Синтез речи (обычно «Google Синтез речи» уже есть).

Кнопка «Назад» в игре возвращает к списку игр, а со списка закрывает приложение.

## Структура

```
app/assets/index.html     все игры (HTML + CSS + JS, один файл)
app/assets/fonts/         шрифты Comfortaa, Rubik и Press Start 2P (для работы без интернета)
app/src/…/MainActivity.java  WebView + голос Android (TextToSpeech)
app/AndroidManifest.xml
app/res/                  иконка и название
build.sh                  сборка APK без Android Studio и Gradle
```

## Сборка

На Ubuntu/Debian:

```bash
sudo apt-get install -y android-sdk-platform-23 aapt dalvik-exchange zipalign apksigner default-jdk
./build.sh            # → dist/dumalki.apk
```

При первой сборке создаётся ключ подписи `keystore/dumalki.jks` (в git не попадает).
Обновление ставится поверх старой версии только если APK подписан тем же ключом.
Чтобы сборки в GitHub Actions подписывались постоянным ключом, добавьте в Settings → Secrets
`KEYSTORE_B64` (вывод `base64 -w0 keystore/dumalki.jks`) и `KS_PASS`.

Новую версию отмечайте в `app/AndroidManifest.xml`: увеличьте `versionCode` и `versionName`.
